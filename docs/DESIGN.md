# 逐浪飞驰 · 玩法与系统说明

## 比赛选择

大厅可以先选六条赛道、五款车型、难度与玩法。单人比赛由本机模拟另外五辆 AI。局域网比赛创建房间后，最多六名真人各自选车型；房主在开赛前决定是否用 AI 补满空位。关闭补位时至少要有两名真人。所有比赛三圈，竞速赛禁用道具和储备氮气，娱乐赛启用七种道具与储备氮气。

六条赛道共享同一套道路宽度与驾驶规则，但长度、弯道密度、坡度、背景色和路线形态不同：晴湾环岛均衡，赤霞风暴多弯，霓虹夜港多长直道，云岭盘山连续回头弯，珊瑚群岛中高速，极光长湾高速环线。方向控制采用物理赛道法线，右转增大横向坐标、左转减小；六图均有方向与无复位单圈测试。

## 驾驶回路

车辆以沿赛道距离、横向偏移和相对车头角度表示。油门、刹车、转向、路面抓地、碰撞和车身位移逐步计算，转弯不会自动把车固定在道路中央。只按油门会离开道路并复位。实体护栏和景物碰撞使用与画面场景一致的碰撞体；联机服务端也构建同一套碰撞体。

按住漂移键并转向会改变转向和抓地。漂移质量结合弯道方向、相对车头角度、按键时长和道路位置计算。有效漂移松开后触发分级小喷，短窗口内松开再点油门触发双喷；娱乐赛的有效漂移还回复能量、强化手中道具。按住过久会降低质量且更容易偏离道路。这使弯道入弯、保持角度、及时回正和二次点油门构成一个完整操作，而非无限按漂移。

## 车型和道具

车型技能属于赛车，不涉及人物：浪潮07的护盾挡住道具后回能；珊瑚12转向快、耗氮低；海风21直线极速及氮气峰值高；脉冲33漂移回能、强化和小喷更强；礁盾45接触碰撞损失更少。每款车都保留直线、弯道、碰撞与能量方面的取舍。具体固定输入下的六图单圈数据见 [README](../README.md)。

娱乐赛共有追踪火箭、感应地雷、护盾、氮气道具、滑油、电磁脉冲和磁力牵引。火箭追击前车；地雷和滑油封路，滑油主要降低抓地；护盾抵御攻击；氮气道具提供持续推进；EMP 清除前车部分能量并暂时禁用氮气；磁力牵引加速自己并拖慢前车。漂移充能可强化部分道具。后排车手拾取防守类补给时会转为追赶工具并获得追赶能量，追尾目标锁定距离也更远。这一补偿只提供追赶机会，不直接调整车辆名次。

## 局域网架构

`npm run lan` 启动 Node HTTP 服务，同时提供静态网页和房间 API。房主生成六位房间码与邀请地址；每位加入者获得独立随机凭据。房主可以修改 AI 补位并开赛，其他玩家只能提交自己的操作。服务端以约 30Hz 推进权威的 `RaceSimulation`，通过 SSE 向房间广播状态与事件；客户端以约 20Hz 提交经过限制的油门、刹车、方向、漂移、氮气、道具和复位输入。服务端负责位置、碰撞、拾取、命中、圈数和名次，浏览器只呈现和输入。失去输入 750ms 后清空该车的操作，防止断线后油门持续按住。

局域网模式以房主电脑为服务端，没有账号、跨公网匹配、断线回放或持久化服务端成绩。单人模式保留浏览器本地最佳纪录。服务停掉后房间消失。联机暂不允许任意一名玩家暂停全场。

## 验证

`npm test` 测驾驶与道具逻辑；`npm run test:e2e` 验证 Chrome 真实 3D 场景与完整单人流程；`npm run test:lan` 验证两人服务端状态和房主权限；`npm run test:e2e:lan` 用两个独立 Chrome 上下文走房间与比赛。自动平衡结果只能说明固定输入下没有一车统治所有赛道，真人操作和道具攻防仍需要试玩迭代。
