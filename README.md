# 逐浪飞驰 · Coastline Rush Plus

基于 [haimingdu20-zachary/coastline-rush-island](https://github.com/haimingdu20-zachary/coastline-rush-island) 的 MIT 许可源码改造。保留原项目的 3D 海岛场景、三圈比赛、声音和实体碰撞系统，扩展为六条赛道、五款有不同被动技能的车型、竞速／娱乐模式，以及同一局域网内最多六名真人的联机比赛。版权与许可见 [LICENSE](LICENSE) 和 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 直接试玩与局域网联机

需要 Node.js 20.19+ 或 22.12+、Chrome 或 Edge 等支持 WebGL 2 的电脑浏览器。项目第一次运行：

```sh
npm ci
npm run build
npm run lan
```

服务器默认监听 `4182` 端口。房主电脑打开终端显示的本机局域网地址，例如 `http://192.168.x.x:4182/`，点击「局域网联机」，输入昵称、选赛道／玩法／车型，创建房间。房间内可以决定是否让 AI 补空位，开赛前也能修改。把房间内显示的**邀请地址**发给同一 Wi-Fi 或局域网中的朋友；朋友打开地址，输入昵称并加入。人数不足时，如果关闭 AI 补位，需要至少两名真人才能开赛。最多六名真人。房主电脑需要保持服务运行；如朋友打不开地址，检查双方是否在同一网络，以及房主电脑防火墙是否允许 `4182` 端口。`PORT=4183 npm run lan` 可改端口。

单人模式直接点击「开始比赛」。开发时可用 `npm run dev`；仅用 Vite 或 `dist/` 静态文件打开页面，**无法创建联机房间**，联机必须使用 `npm run lan` 的 Node 服务。无需账号、云服务器或外网端口映射。

## 玩法

六条赛道各有走线侧重：**晴湾环岛**均衡、**赤霞风暴**密集弯、**霓虹夜港**高速直道、**云岭盘山**连续回头弯、**珊瑚群岛**中高速海岸、**极光长湾**长距离冲刺。竞速赛没有道具箱和储备氮气，靠走线、刹车、漂移小喷决胜；娱乐赛有氮气及七种道具：追踪火箭、感应地雷、护盾、氮气道具、滑油、电磁脉冲和磁力牵引。后方车手拾取防守类道具时更可能得到追击／赶超工具，并额外回复少量能量；后方火箭锁定范围也更长。

| 车型 | 被动技能与优势 | 代价 |
| --- | --- | --- |
| 浪潮07 | 均衡驾驶；护盾挡住道具后回复能量 | 没有专项极速优势 |
| 珊瑚12 | 转向敏捷、起步快、氮气消耗低 | 直路极速较低，碰撞损失较大 |
| 海风21 | 直道极速和氮气峰值高 | 起步、转向较慢，氮气消耗更快 |
| 脉冲33 | 有效漂移回能快、强化道具更快、小喷更强 | 直线极速略低，碰撞损失较大 |
| 礁盾45 | 接触对手后更能保住速度，转向灵活 | 极速和小喷不如专项车型 |

`W/↑` 油门、`S/↓` 刹车、`A/←` 左转、`D/→` 右转。**方向键 + Space** 漂移；在「驾驶指南」可把漂移键改成 Shift、C 或 F，设置会保存在当前浏览器。若把 Shift 设为漂移，储备氮气会自动改为 Space。`R` 复位会退回上一个安全路段，不能用来免费过弯。娱乐赛中 `E` 使用道具。单人可按 `Esc` 暂停；联机比赛由房主电脑持续模拟，不能由一名玩家暂停全场。六条赛道的左右物理方向均有自动测试。

入弯前看路况适当减速，同时按方向键和漂移键。HUD 的漂移蓄力条会随持续时间、方向与弯道匹配程度、车身角度及路肩位置变化；及时松开触发**出弯小喷**，松开油门再点按可接**双喷**。有效漂移还会积攒氮气、强化手中道具。直路空漂几乎不蓄力，漂移过久也会降低质量并冲出赛道。只按油门不能自动矫正通过弯道：在六条赛道的 120 秒模拟中均无法完成一圈；正常转向、漂移并在急弯减速则均可完成。

## 平衡验收数据

以下为 `node --import tsx scripts/balance.ts` 的固定种子第一圈秒数：同一走线脚本、竞速模式、无对手接触。脚本会主动转向、在弯道漂移，并在赤霞风暴急弯将车速限制在约 40–42 m/s；数据用于比较该操作方式下的趋势，并非真人极限成绩。30 种赛道／车型组合均无复位完成一圈。

| 赛道 | 浪潮07 | 珊瑚12 | 海风21 | 脉冲33 | 礁盾45 | 本条件最快 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 晴湾环岛 | 26.81 | 27.36 | 26.28 | 26.75 | 27.26 | 海风21 |
| 赤霞风暴 | 42.19 | 42.08 | 44.67 | 42.19 | 42.17 | 珊瑚12 |
| 霓虹夜港 | 27.94 | 28.74 | 27.32 | 28.14 | 28.46 | 海风21 |
| 云岭盘山 | 27.72 | 28.47 | 27.13 | 27.84 | 28.21 | 海风21 |
| 珊瑚群岛 | 26.94 | 27.69 | 26.35 | 27.14 | 27.43 | 海风21 |
| 极光长湾 | 31.48 | 32.37 | 30.65 | 31.73 | 32.02 | 海风21 |

这些计时显示，在这种脚本走线下海风21仍占多数赛道的最快，车型差异还需要真人按不同走线、道具对抗与碰撞进一步验证。漂移的主要可测收益是更小的出弯偏移、有效小喷、氮气和道具充能；例如赤霞风暴海风21在相同 40 m/s 限速下不漂移无法完成一圈，使用漂移可在 44.67 秒无复位完成。赛道不能靠直线加速直接穿过。

## 测试

- `npm test`：模拟、方向、漂移／双喷、七种道具效果、碰撞、存档、赛道和车型平衡。
- `npm run test:e2e`：Chrome 中的单人比赛、真实场景碰撞、菜单及窄屏布局。
- `npm run test:lan`：真实 HTTP/SSE 双人房间、同步驾驶、房主权限和 AI 补位。
- `npm run test:e2e:lan`：先运行 `npm run build` 和 `npm run lan`，再用两个独立 Chrome 浏览器上下文走完整加入与开赛流程。

联机房间运行于房主电脑；没有账号、跨网络匹配、断线回放或持久化服务端成绩。
